## Step-by-Step Guide to Integrate Cashfree in Alkaa (Testing Mode)

Integrating Cashfree for payouts in Alkaa allows automated employee salary transfers in your multi-tenant HR system, building on our previous discussions. Since you're focusing on testing mode, we'll use Cashfree's sandbox environment to simulate payouts without real money movement. This ensures safe testing before going live. The process aligns with Alkaa's Node.js/Express.js backend, Prisma ORM, and React frontend.

Cashfree's sandbox mode mimics production but uses test data (e.g., dummy bank accounts and UPI IDs) for validation[1][2][3]. All payouts in sandbox are simulated and don't reach actual banks[4].

### 1. Set Up Cashfree Account in Testing Mode
   - Sign up for a free Cashfree merchant account at cashfree.com if you haven't already[2][5].
   - Log in to your Cashfree dashboard and switch to the **Test Environment** (sandbox) by clicking "Switch to Test" in the top-right corner[6][3]. This creates a separate testing space.
   - Navigate to **Developers** > **API Keys** in the dashboard.
   - Click **Generate API Keys** to get your test **App ID** (Client ID) and **Secret Key**[2][7]. Download and store them securely (e.g., in environment variables). These are for sandbox only—production keys differ.
   - Enable **Payouts** in your dashboard under **Payment Products** > **Payouts**. For multi-tenancy, you can set up virtual accounts later, but start with a single test account[2][8].
   - Review test data: Use Cashfree's provided dummy beneficiary details (e.g., bank account: 3333333333, IFSC: YESB0CMSNOC) for simulations[4]. Test mode supports IMPS, NEFT, RTGS, and UPI[3].

### 2. Update Alkaa's Backend (Node.js/Express.js)
   Install and configure the Cashfree SDK in Alkaa's backend to handle payout APIs. Focus on the payroll module for employee transfers.

   - **Install Dependencies**: Run `npm install cashfree-pg` (Cashfree's Node.js SDK supports payouts)[9].
   - **Configure Environment**: In your `.env` file, add sandbox credentials:
     ```
     CASHFREE_APP_ID=your_test_app_id
     CASHFREE_SECRET_KEY=your_test_secret_key
     CASHFREE_ENVIRONMENT=sandbox  # Use 'production' later
     ```
   - **Create a Payout Service**: In `src/services/payrollService.js` (or a new file), add functions for payouts. Adapt for multi-tenancy by fetching company-specific details from Prisma.
     ```javascript
     const { Cashfree } = require('cashfree-pg');

     Cashfree.XClientId = process.env.CASHFREE_APP_ID;
     Cashfree.XClientSecret = process.env.CASHFREE_SECRET_KEY;
     Cashfree.XEnvironment = Cashfree.Environment.SANDBOX;  // Testing mode

     async function createPayout(companyId, userId, amount, employeeBankDetails) {
       // Fetch company/manager bank details from Prisma (for multi-tenancy)
       const company = await prisma.company.findUnique({ where: { id: companyId }, include: { bankDetails: true } });
       if (!company.bankDetails) throw new Error('Company bank details missing');

       try {
         // Add beneficiary (employee) if not exists
         const beneficiary = {
           beneId: `emp_${userId}`,
           name: employeeBankDetails.name,
           email: employeeBankDetails.email || 'test@cashfree.com',
           phone: employeeBankDetails.phone || '9999999999',
           bankAccount: employeeBankDetails.accountNumber,
           ifsc: employeeBankDetails.ifsc,
           address1: 'Test Address'
         };
         await Cashfree.PGCreateBeneficiary(beneficiary);  // Simulate in sandbox[19]

         // Initiate payout
         const payoutRequest = {
           beneId: beneficiary.beneId,
           amount: amount,
           transferId: `salary_${userId}_${Date.now()}`,
           transferMode: 'imps'  // Test with IMPS/NEFT in sandbox[16]
         };
         const payout = await Cashfree.PGCreateTransfer(payoutRequest);

         return payout;
       } catch (error) {
         throw new Error(`Payout failed: ${error.message}`);
       }
     }
     ```
     - This handles adding beneficiaries (employees) and initiating transfers from the company's linked account[10][11][8]. In sandbox, use test data to avoid real transactions[4].

   - **Add API Endpoint**: In `src/routes/v3/payroll.js`, create a route for testing payouts, with authentication.
     ```javascript
     const express = require('express');
     const router = express.Router();
     const { authenticate, authorize } = require('../middleware/auth');
     const payrollService = require('../services/payrollService');

     router.post('/payout/:userId', authenticate, authorize(['finance_manager', 'org_admin']), async (req, res) => {
       try {
         const { userId } = req.params;
         const { amount, companyId } = req.body;
         const user = await prisma.user.findUnique({ where: { id: userId }, include: { bankDetails: true } });
         if (!user.bankDetails) throw new Error('Employee bank details missing');

         const payoutResult = await payrollService.createPayout(companyId, userId, amount, user.bankDetails);

         // Update SalaryRecord in Prisma (for testing tracking)
         await prisma.salaryRecord.update({
           where: { id: req.body.salaryRecordId },
           data: { status: 'PAID', paymentRef: payoutResult.referenceId, processedAt: new Date() }
         });

         res.json({ success: true, data: payoutResult, message: 'Test payout initiated (sandbox mode)' });
       } catch (error) {
         res.status(500).json({ success: false, error: error.message });
       }
     });
     ```
   - **Handle Webhooks**: Add an endpoint for Cashfree webhooks to simulate status updates (e.g., success/failure) in sandbox[2].

### 3. Update Database Schema (Prisma)
   Enhance the schema to track Cashfree-specific payout data. Edit `prisma/schema.prisma` and run `npx prisma migrate dev`.
   ```prisma
   model SalaryRecord {
     // Existing fields
     payoutStatus     String?  // e.g., 'INITIATED', 'SUCCESS', 'FAILED'
     payoutProvider   String?  @default("Cashfree")
     payoutId         String?  // Cashfree's reference ID
     payoutMode       String?  // e.g., 'IMPS'
   }
   ```
   - Ensure the `BankDetails` model has fields like `accountNumber`, `ifsc`, and `name` for both managers/companies and employees[12].

### 4. Update Frontend (React)
   Add UI elements in the Payroll dashboard to initiate test payouts.
   - In `src/pages/payroll/PayrollPage.tsx`, add a button that calls the new backend API.
     ```tsx
     import { useState } from 'react';
     import api from '../services/api';

     const PayrollItem = ({ salaryRecord, companyId }) => {
       const [loading, setLoading] = useState(false);

         setLoading(true);
     ```

### 5. Security and Testing
   - **Secure Setup**: Use HTTPS and encrypt bank details. Test authentication ensures only authorized roles (e.g., finance_manager) can initiate payouts.
   - **Sandbox Testing**: Use Cashfree's test data for beneficiaries and simulate transfers[3][4]. Check statuses via webhooks or API (e.g., getTransferStatus)[10][11].
   - **Unit/Integration Tests**: Add Jest tests for the payout service. Use E2E tests with Playwright to simulate full workflows.
   - **Multi-Tenancy Testing**: Verify payouts isolate per company by testing with multiple tenant IDs.
   - **Error Handling**: Implement retries and logging for simulated failures in sandbox.

### 6. Deployment and Go-Live Preparation
   - Deploy to a staging environment mirroring sandbox.
   - Monitor via Alkaa's ELK stack. Once tested, switch to production by updating `.env` to `CASHFREE_ENVIRONMENT=production` and using live keys[9].
   - For production, complete KYC and fund your Cashfree account[5][8].

This integration should work seamlessly with Alkaa's payroll flow. Test thoroughly in sandbox to avoid issues—Cashfree provides dashboards for monitoring test transactions[1][11]. If you need code adjustments for specific multi-tenant scenarios, let me know!
